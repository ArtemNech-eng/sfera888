Я тебе прислал недавно документ по апи авито объявления смотри в него и в разделе «Аналитика Авито» 
расширь информацию по объявлениям.

Для каждого объявления 
подтянуть и показать:

=== КАРТОЧКА ОБЪЯВЛЕНИЯ ===

При нажатии на объявление 
в таблице — открывается 
подробная карточка:

Основная информация:
— Название объявления
— ID объявления в Авито
— Город
— Категория услуги
— Статус (активно / неактивно / 
  заблокировано)
— Дата публикации
— Ссылка на объявление в Авито 
  (кнопка «Открыть в Авито»)

Статистика за период 
(переключатель: день / неделя / месяц):
— Просмотры
— Контакты (звонки + сообщения)
— Конверсия просмотр → контакт (%)
— Добавления в избранное

Наша аналитика 
(считается из CRM):
— Заявок создано из этого объявления
— Заказов оплачено
— Конверсия контакт → заявка (%)
— Конверсия заявка → оплата (%)
— Общий доход с объявления
— Стоимость одного контакта
— Стоимость одного заказа
— ROI

Графики (за последние 30 дней):
— Просмотры по дням (линейный)
— Контакты по дням (линейный)
— Оба на одном графике 
  для сравнения

Рекомендация системы:

Если ROI > 5:
🔥 «Суперэффективное! 
Увеличьте бюджет на продвижение.»

Если ROI 3-5:
🟢 «Хорошо работает. 
Оставьте как есть.»

Если ROI 1.5-3:
🟡 «Средняя эффективность. 
Попробуйте обновить фото 
или заголовок.»

Если ROI < 1.5:
🔴 «Не окупается. 
Рекомендуется отключить 
или полностью переделать.»

Если конверсия просмотр→контакт < 5%:
⚠️ «Мало кликают. 
Смените заголовок или 
главное фото.»

Если конверсия контакт→заявка < 20%:
⚠️ «Много обращений, мало заявок. 
Клиенты уходят после первого 
сообщения. Проверьте скорость 
ответа и скрипты.»

=== УПРАВЛЕНИЕ ОБЪЯВЛЕНИЕМ ===

Кнопки в карточке:

[🟢 Включить] / [🔴 Выключить]
— Активирует/деактивирует 
  объявление через Авито API
— Менять статус прямо из CRM

[🔗 Открыть в Авито]
— Открывает объявление 
  на Авито в новой вкладке
— Для редактирования текста 
  и фото

=== ПРИВЯЗКА ЗАЯВКИ К ОБЪЯВЛЕНИЮ ===

Когда ассистент создаёт заявку 
из чата Авито — автоматически 
определять из какого объявления 
пришёл клиент.

Авито API в чате показывает 
к какому объявлению 
относится сообщение.

Сохранять привязку:
заявка → объявление

Это позволит считать 
стоимость заказа и ROI 
по каждому объявлению.
