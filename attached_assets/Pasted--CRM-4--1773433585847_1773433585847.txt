Создай веб-приложение CRM для управления 
ремонтными заказами. 

Система имеет 4 роли пользователей 
с разным уровнем доступа:

=== РОЛЬ 1: АДМИН ===
Видит всё. Полный доступ ко всем данным.

Функционал админа:
- Дашборд: количество заявок сегодня/неделя/месяц, 
  количество заказов, доход за период, 
  задолженности мастеров, конверсия заявки→заказы
- Управление пользователями: добавление/удаление 
  операторов
- Просмотр всех заявок, заказов, мастеров, 
  клиентов, финансов
- Аналитика: воронка продаж, стоимость заявки, 
  средний чек, рейтинг мастеров, 
  статистика по городам
- Настройки: города, виды услуг, 
  тарифы комиссий

=== РОЛЬ 2: ОПЕРАТОР ЗАЯВОК ===
Работает с входящими заявками от клиентов.
НЕ видит мастеров, НЕ видит оператора мастеров, 
НЕ видит финансы.

Функционал:
- Видит список входящих заявок
- Создаёт новую заявку вручную 
  (поля: имя клиента, телефон, город, район, 
  вид работ, площадь, комментарий, 
  источник заявки)
- Меняет статус заявки: 
  новая / в обработке / отправлена в работу / 
  нецелевая / отказ клиента
- Когда нажимает "отправить в работу" — 
  заявка попадает в БУФЕР ЗАКАЗОВ, 
  но БЕЗ имени и телефона клиента 
  (только город, район, вид работ, площадь, 
  когда нужно, комментарий)

=== БУФЕР ЗАКАЗОВ (среднее окно) ===
Промежуточная зона между оператором заявок 
и оператором мастеров.

Содержит обезличенные заявки:
- ID заявки
- Город
- Район
- Вид работ
- Площадь
- Когда нужно
- Комментарий
- Статус: ожидает мастера / назначен мастер / 
  в работе / завершён

НЕ содержит:
- Имя клиента
- Телефон клиента
- Источник заявки

=== РОЛЬ 3: ОПЕРАТОР МАСТЕРОВ ===
Работает с буфером заказов и распределяет 
по мастерам.
НЕ видит клиентов (имена, телефоны), 
НЕ видит оператора заявок, НЕ видит финансы.

Функционал:
- Видит список заявок из буфера
- Видит список мастеров 
  (только ID/псевдоним мастера, город, 
  специализация, рейтинг, статус — 
  БЕЗ телефона мастера)
- Назначает мастера на заявку
- После назначения — контакт клиента 
  автоматически отправляется ТОЛЬКО мастеру 
  через Telegram-бот (оператор мастеров 
  НЕ видит контакт клиента)
- Видит статус заказа 
  (принят мастером / в работе / завершён)

=== РОЛЬ 4: МАСТЕР ===
Получает заказы через Telegram-бот.
НЕ имеет доступа к CRM.

Telegram-бот для мастера:
- Получает уведомление о новом заказе 
  (город, район, вид работ, площадь, 
  имя и телефон клиента, размер комиссии)
- Кнопки: принять / отклонить
- Таймер: 1 час на ответ, 
  если не ответил — заказ отзывается
- Команда /status — свой рейтинг 
  и статистика
- Команда /history — история заказов
- Команда /balance — задолженность 
  по комиссиям

=== СИСТЕМА РЕЙТИНГА МАСТЕРОВ ===
Автоматический рейтинг 1.0-5.0

Параметры:
- Конверсия (принятые заявки / 
  переданные заявки): вес 30%
- Берёт все заказы включая мелкие: вес 25%
- Скорость ответа: вес 20%
- Оценка клиента: вес 15%
- Своевременная оплата комиссии: вес 10%

Распределение заказов по рейтингу:
- 4.5-5.0: получает заказы первым, 
  включая крупные
- 3.5-4.4: обычный порядок
- 2.5-3.4: только мелкие заказы
- ниже 2.5: заказы приостановлены

=== ФИНАНСЫ (только админ) ===
Автоматический расчёт комиссии:
- Заказ до 50 000₽ → комиссия 5 000₽
- Заказ свыше 50 000₽ → комиссия 15%
- Заказ свыше 100 000₽ → ручной ввод

Таблица транзакций:
- Дата, мастер, заказ, сумма заказа, 
  комиссия, статус оплаты
- Общий доход за период
- Задолженности

=== ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ ===
- Авторизация по логину и паролю
- Адаптивный дизайн (работает с телефона)
- База данных для хранения всех данных
- Интеграция с Telegram Bot API
- Чистый минималистичный дизайн
- Русский язык интерфейса
