Создай PWA (Progressive Web App) 
для мастеров ремонтной компании.

Приложение должно работать 
как мобильное приложение — 
с возможностью добавления 
на главный экран телефона.

=== АВТОРИЗАЦИЯ ===
Мастер входит по логину и паролю 
(которые получает при регистрации 
в CRM рекрутером).

=== ГЛАВНЫЙ ЭКРАН ===
— Приветствие с именем мастера
— Рейтинг (звёзды из 5)
— Задолженность по комиссиям 
  (красным если есть долг)
— Блок «Новые заказы» — 
  карточки заказов ожидающих ответа
— Блок «В работе» — 
  текущие заказы

=== ЭКРАН НОВОГО ЗАКАЗА ===
Карточка заказа:
— Город и район
— Вид работ
— Примерная площадь
— Когда нужно клиенту
— Размер комиссии
— Таймер обратного отсчёта (1 час)
— Кнопка «Принять» (зелёная, крупная)
— Кнопка «Отклонить» (серая)

После принятия появляется:
— Имя клиента
— Телефон клиента 
  (кнопка «Позвонить» — 
  открывает звонилку телефона)

Если не ответил за 1 час — 
заказ автоматически исчезает 
и возвращается диспетчеру в CRM.

=== ЭКРАН МОИ ЗАКАЗЫ ===
Список карточек заказов.

Статусы заказа 
(мастер переключает сам):
— Принят
— Выехал на замер
— На объекте (работаю)
— Завершён

В карточке заказа:
— Данные клиента (имя, телефон, адрес)
— Кнопка «Позвонить»
— Поле «Сумма заказа» (ввод числа)
— Загрузка фото ДО (кнопка → 
  открывает камеру телефона)
— Загрузка фото ПОСЛЕ (кнопка → 
  открывает камеру телефона)
— Загрузка акта (фото)
— Кнопка «Завершить заказ»

При нажатии «Завершить» — 
проверяет что заполнены:
сумма, фото до, фото после, акт.
Если не заполнено — показать ошибку.

Фильтры: все / активные / завершённые

=== ЭКРАН БАЛАНС ===
— Общий заработок за месяц 
  (сумма всех заказов)
— Оплачено комиссий
— Задолженность (красным если есть)
— Список всех комиссий:
  дата, заказ, сумма, комиссия, 
  статус (оплачено / не оплачено)
— Реквизиты для оплаты комиссии 
  (номер карты / телефон)

=== ЭКРАН ПРОФИЛЬ ===
— Имя
— Город
— Специализация
— Рейтинг (подробно по параметрам):
  • Конверсия заявок
  • Пунктуальность
  • Берёт все заказы
  • Оценки клиентов
  • Оплата комиссий
— Портфолио (галерея фото работ)
— Кнопка «Написать в поддержку»
— Кнопка «Выйти»

=== НИЖНЕЕ МЕНЮ ===
4 иконки внизу экрана:
🏠 Главная | 📋 Заказы | 💰 Баланс | 👤 Профиль

=== УВЕДОМЛЕНИЯ ===
Push-уведомления:
— Новый заказ
— Напоминание об оплате комиссии
— Изменение рейтинга

=== ДИЗАЙН ===
— Мобильный вид (как приложение)
— Тёмная или светлая тема
— Крупные кнопки 
  (мастера работают грязными руками)
— Минимум текста, максимум 
  понятных иконок
— Быстрая загрузка
— Работа при слабом интернете

=== PWA ТРЕБОВАНИЯ ===
— manifest.json для установки 
  на главный экран
— Service Worker для кеширования
— Иконка приложения
— Splash screen при загрузке
— Работа в полноэкранном режиме
