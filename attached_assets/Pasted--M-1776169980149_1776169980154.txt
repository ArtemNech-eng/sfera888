В раздел «ИИ Офис» обнови 
сценарий «💰 Напомнить об оплате».

Все уведомления — 
только через Max Messenger.
Telegram не используем.
Автоматических действий 
с заказами нет.
Только Админ принимает решение.

=== ЛОГИКА ПОИСКА ===

Найти все заказы где:
— Смета отправлена клиенту
— Предоплата НЕ оплачена
— Прошло более 24 часов 
  с момента отправки сметы

Сгруппировать по срокам:

🟡 24-48 часов без оплаты
🔴 48-72 часа без оплаты
⚫ Более 72 часов без оплаты

=== УВЕДОМЛЕНИЯ МАСТЕРУ В MAX ===

Шаблон 24-48 часов:
«👋 {имя_мастера}, добрый день!

По заказу #{номер_заказа} 
({вид_работ}, {район}) 
клиент пока не оплатил 
предоплату.

Напомните клиенту про бронь — 
одно сообщение часто 
решает вопрос 👍

Если клиент отказался — 
сообщите нам, 
и мы подготовим 
новый заказ для вас.»

Шаблон 48-72 часа:
«⚠️ {имя_мастера}, 
по заказу #{номер_заказа} 
предоплата не поступила 
уже {часов} часов.

Пожалуйста ещё раз 
напомните клиенту про бронь.

Если клиент не планирует 
оплачивать — 
сообщите нам, 
мы решим что делать 
с этим заказом.»

Шаблон более 72 часов:
«{имя_мастера}, 
по заказу #{номер_заказа} 
предоплата не поступила 
уже {часов} часов.

Вопрос передан руководителю.
Ожидайте — мы свяжемся с вами.»

=== УВЕДОМЛЕНИЕ АДМИНУ В MAX ===

При обнаружении заказа 
без оплаты более 72 часов — 
отправить АДМИНУ в Max:

«⚠️ ПРЕДОПЛАТА НЕ ОПЛАЧЕНА 72+ ЧАСОВ

Заказ: #{номер_заказа}
Вид работ: {вид_работ}
Город: {город}, {район}
Мастер: {имя_мастера}
Клиент: {имя_клиента}
Смета отправлена: {дата}
Сумма заказа: {сумма}₽
Предоплата: 5 000₽
Часов без оплаты: {часов}

Решение принимается в ИИ Офис → 
Напомнить об оплате»

=== ЭКРАН В ИИ ОФИСЕ ===

Сводка вверху — 4 карточки:

Карточка 1:
⚫ Более 72ч без оплаты: X заказов

Карточка 2:
🔴 48-72ч без оплаты: X заказов

Карточка 3:
🟡 24-48ч без оплаты: X заказов

Карточка 4:
💰 Ожидается предоплат: X₽
(крупный зелёный шрифт)

Таблица проблемных заказов:

Столбцы:
— Номер заказа
— Мастер
— Клиент
— Город, район
— Вид работ
— Сумма заказа
— Смета отправлена (дата)
— Часов без оплаты
— Статус риска (⚫/🔴/🟡)
— Действия

Цвет строк:
⚫ 72ч+: тёмно-красный фон (#FFE0E0)
🔴 48-72ч: светло-красный фон (#FFF0F0)
🟡 24-48ч: светло-жёлтый фон (#FFFDE7)

Сортировка: 
по часам без оплаты — 
самые старые сверху.

=== КНОПКИ ДЕЙСТВИЙ ===

В каждой строке таблицы 
4 кнопки:

[📱 Написать мастеру]
— Отправить мастеру в Max 
  шаблон по сроку 
  (24-48ч / 48-72ч / 72ч+)
— Показать: «✅ Сообщение отправлено»
— Записать дату и время отправки

[📞 Позвонить клиенту]
— Показать номер телефона клиента
— Кнопка набора номера
— После звонка — 
  поле для комментария:
  «Что сказал клиент?»
— Кнопка «Сохранить комментарий»

[🔄 Вернуть в пул]
— Показать подтверждение:
  «Вернуть заказ #{номер} в пул?
  Мастер {имя} получит уведомление.
  [Да, вернуть] [Отмена]»
  
— Если «Да»:
  — Статус заказа → «ищем мастера»
  — Мастеру в Max:
    «Заказ #{номер_заказа} 
    возвращён в пул — 
    клиент не оплатил предоплату.
    
    Из 10 клиентов 8 оплачивают 
    без проблем — 
    те кто не платит, 
    обычно проблемные.
    
    Готовим для вас 
    новый заказ 👍»
  — Записать в историю

[❌ Отменить заказ]
— Показать подтверждение:
  «Отменить заказ #{номер}?
  Это действие нельзя отменить.
  [Да, отменить] [Нет]»
  
— Если «Да»:
  — Статус заказа → «отменён»
  — Мастеру в Max:
    «Заказ #{номер_заказа} отменён.
    Причина: клиент 
    не оплатил предоплату.»
  — Записать в историю

=== ВАЖНО ===

Автоматических действий 
с заказами нет.

Система только:
✅ Находит заказы без оплаты
✅ Отправляет напоминания мастерам
✅ Уведомляет админа в Max
✅ Показывает кнопки действий

Решение принимает ТОЛЬКО АДМИН:
✅ Написать мастеру
✅ Позвонить клиенту
✅ Вернуть в пул
✅ Отменить заказ
✅ Ничего не делать (подождать)

=== ЗАПУСК ===

Ручной:
— Кнопка «▶️ Запустить сейчас»
— Результат показать сразу 
  на экране

Автоматический:
— Каждые 6 часов:
  9:00, 15:00, 21:00
— Переключатель вкл/выкл
— При авто-запуске — 
  только отправка напоминаний,
  без действий с заказами

=== ИСТОРИЯ ЗАПУСКОВ ===

Таблица:
Дата | Время | Тип (ручной/авто) | 
Найдено | Напоминаний отправлено | 
Возвращено в пул | 
Отменено | Ошибки

=== ЛОГИРОВАНИЕ ===

Каждый запуск записывать:
— Дата и время
— Тип: ручной / авто
— Найдено заказов без оплаты
  (по каждой группе отдельно)
— Отправлено напоминаний мастерам
— Уведомлений отправлено 
  админу в Max
— Возвращено в пул 
  (по решению админа)
— Отменено (по решению админа)
— Ошибки если были

Если ошибка при отправке 
в Max — записать в лог 
и показать в истории:
«⚠️ Не удалось отправить 
сообщение мастеру {имя}: 
{текст ошибки}»
