Переделай интеграцию с Авито API.
Работай СТРОГО по официальной 
документации Авито:
https://developers.avito.ru/api-catalog

Домен CRM: https://sfera-master.ru
Авито уже подключён, токен есть.

Изучи документацию Авито API 
по каждому пункту ниже 
и реализуй ТОЧНО по ней.

=== 1. ПОЛУЧЕНИЕ СООБЩЕНИЙ ===

Документация:
https://developers.avito.ru/api-catalog/messenger/documentation

Используй endpoint из документации 
для получения списка чатов 
и сообщений.

Реализуй:
— Каждые 30 секунд проверять 
  новые сообщения
— Сохранять в базу:
  ID чата, ID сообщения, 
  имя клиента, текст, 
  дата, статус (новое/прочитано)

=== 2. ОТПРАВКА СООБЩЕНИЙ ===

Документация:
https://developers.avito.ru/api-catalog/messenger/documentation

Используй endpoint из документации 
для отправки сообщений в чат.

Реализуй:
— Поле ввода текста в CRM
— Кнопка «Отправить»
— Сообщение отправляется 
  в Авито чат клиенту
— Сохраняется в базе CRM

=== 3. ЭКРАН СООБЩЕНИЙ В CRM ===

В боковом меню добавить:
«💬 Сообщения Авито»

Доступен: Админ и Ассистент

Экран как мессенджер:

Левая панель — список чатов:
— Имя клиента
— Последнее сообщение (превью 
  первые 50 символов)
— Время последнего сообщения
— Индикатор:
  🔴 непрочитано
  🟢 отвечено
  🔵 создана заявка

Правая панель — переписка:
— История сообщений
— Сообщения клиента слева 
  (светло-серый фон)
— Наши ответы справа 
  (зелёный фон)
— Поле ввода внизу
— Кнопка «Отправить»

Над перепиской кнопки:
[📋 Создать заявку]
[📞 Показать телефон]

=== 4. БЫСТРЫЕ ОТВЕТЫ ===

Над полем ввода — кнопки:

[Цены] — вставляет в поле:
«Здравствуйте!
Обои от 300₽/м²
Шпаклёвка от 350₽/м²
Покраска от 200₽/м²
Плитка от 1200₽/м²

Подскажите:
1. Какой район?
2. Примерная площадь?
3. Когда хотите начать?»

[Мастер] — вставляет:
«Отлично! Сейчас подберу мастера 
из вашего района.
Он свяжется с вами в течение часа.
Скиньте номер для связи 👍»

[Гарантия] — вставляет:
«После работы выдаём 
гарантийный сертификат на 2 года.
Если что-то отклеится — 
переделаем бесплатно 👍»

[Бригада] — вставляет:
«Да, мы частная бригада, 
работаем по районам.
Цены одинаковые.
Кто ближе — тот и выезжает.»

Быстрые ответы настраиваются 
админом в настройках 
(добавить/удалить/редактировать).

=== 5. СОЗДАНИЕ ЗАЯВКИ ИЗ ЧАТА ===

Кнопка «Создать заявку» в чате:

Открывает форму с предзаполнением:
— Источник: Авито (автоматически)
— Имя клиента: из Авито 
  (автоматически)
— Привязка к чату: автоматически
— Город: [выбрать]
— Вид работ: [выбрать]
— Район: [ввести]
— Площадь: [ввести]
— Когда нужно: [выбрать]
— Комментарий: [ввести]

После создания заявки:
— Чат помечается 🔵
— В карточке заявки — 
  ссылка на чат

=== 6. СТАТИСТИКА ОБЪЯВЛЕНИЙ ===

Документация:
https://developers.avito.ru/api-catalog/stats/documentation

Используй endpoint из документации 
для получения статистики.

Реализуй экран «📊 Статистика Авито»:

Таблица объявлений:
— Название
— Просмотры (день/неделя/месяц)
— Контакты (день/неделя/месяц)
— Стоимость контакта
— Статус (активно/неактивно)

Цвет стоимости контакта:
🟢 до 150₽
🟡 150-300₽
🔴 больше 300₽

Обновлять каждые 6 часов 
автоматически.

Доступен: Админ и Ассистент

=== 7. БАЛАНС АВИТО ===

Документация:
https://developers.avito.ru/api-catalog/user-balance/documentation

Используй endpoint из документации 
для получения баланса.

Показывать в дашборде:
«💰 Баланс Авито: X₽»

Если баланс < 1000₽:
— Красным цветом
— Уведомление админу

Обновлять каждый час.

Доступен: Админ и Ассистент

=== 8. ИНФОРМАЦИЯ О ПОЛЬЗОВАТЕЛЕ ===

Документация:
https://developers.avito.ru/api-catalog/user/documentation

Используй endpoint для получения 
информации об аккаунте.

Показать в настройках Авито:
— Имя аккаунта
— ID пользователя
— Статус подключения 
  🟢 / 🔴

=== 9. ОБНОВЛЕНИЕ ТОКЕНА ===

Документация:
https://developers.avito.ru/api-catalog/auth/documentation

Автоматическое обновление токена 
перед каждым запросом:

Если token_expires_at < 
текущее время:
— Отправить запрос на обновление 
  по документации
— Сохранить новый access_token 
  и refresh_token в базу
— Обновить expires_at

=== 10. УВЕДОМЛЕНИЯ ===

При новом сообщении:
— Счётчик непрочитанных 
  на иконке «💬» в меню
— Звук уведомления

При низком балансе:
— Уведомление админу
