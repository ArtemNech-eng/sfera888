Интегрируй Авито API с CRM.
Домен CRM: https://sfera-master.ru
Авито API уже подключён, 
токен сохранён в базе данных.

=== 1. ПОЛУЧЕНИЕ СООБЩЕНИЙ ИЗ АВИТО ===

Каждые 30 секунд проверять 
новые сообщения из Авито.

API запрос:
GET https://api.avito.ru/messenger/v3/accounts/{user_id}/chats
Headers: 
Authorization: Bearer {access_token}

Для каждого чата получить сообщения:
GET https://api.avito.ru/messenger/v3/accounts/{user_id}/chats/{chat_id}/messages

Новые сообщения сохранять в базу:
— ID чата Авито
— ID сообщения
— Имя клиента (из профиля Авито)
— Текст сообщения
— Дата и время
— Статус: новое / прочитано
— Привязка к заявке (если создана)

=== 2. ЭКРАН СООБЩЕНИЙ В CRM ===

В боковое меню добавить пункт 
«💬 Сообщения Авито»

Левая панель — список чатов:
— Имя клиента
— Последнее сообщение (превью)
— Время последнего сообщения
— Индикатор: 
  🔴 новое непрочитанное
  🟢 отвечено
  🔵 создана заявка

Сортировка: 
новые непрочитанные сверху

Правая панель — переписка:
— Вся история сообщений с клиентом
— Сообщения клиента — слева
— Наши ответы — справа
— Поле ввода ответа внизу
— Кнопка «Отправить»

Над перепиской — кнопки:
— [📋 Создать заявку] — 
  открывает форму создания заявки 
  с предзаполненным именем клиента
— [📞 Телефон клиента] — 
  показать если есть

=== 3. ОТПРАВКА ОТВЕТОВ В АВИТО ===

Когда ассистент пишет ответ в CRM 
и нажимает «Отправить»:

POST https://api.avito.ru/messenger/v3/accounts/{user_id}/chats/{chat_id}/messages
Headers:
Authorization: Bearer {access_token}
Content-Type: application/json
Body:
{
  "message": {
    "text": "текст ответа"
  }
}

Сообщение отправляется в Авито 
и сохраняется в базе CRM.

Клиент видит ответ в своём Авито.

=== 4. БЫСТРЫЕ ОТВЕТЫ ===

Над полем ввода — 
кнопки быстрых ответов:

[Цены] — вставляет:
«Здравствуйте!
Обои от 300₽/м²
Шпаклёвка от 350₽/м²
Покраска от 200₽/м²
Плитка от 1200₽/м²

Подскажите:
1. Какой район?
2. Примерная площадь?
3. Когда хотите начать?»

[Мастер приедет] — вставляет:
«Отлично! Сейчас подберу мастера 
из вашего района. 
Он свяжется с вами в течение часа 
и договоритесь по времени.
Скиньте номер для связи 👍»

[Гарантия] — вставляет:
«После работы выдаём 
гарантийный сертификат на 2 года.
Если что-то отклеится — 
приедем и переделаем бесплатно 👍»

[Бригада] — вставляет:
«Да, мы частная бригада, 
работаем по районам. 
Цены одинаковые. 
Кто ближе — тот и выезжает.»

Кнопки быстрых ответов 
настраиваются админом 
в настройках.

=== 5. СОЗДАНИЕ ЗАЯВКИ ИЗ ЧАТА ===

Когда ассистент нажимает 
«Создать заявку» в чате:

Открывается форма заявки 
с предзаполненными полями:
— Источник: Авито (автоматически)
— Имя клиента: 
  из профиля Авито (автоматически)
— Ссылка на чат: 
  привязана (автоматически)
— Город: [выбрать]
— Вид работ: [выбрать]
— Район: [ввести]
— Площадь: [ввести]
— Комментарий: [ввести]

После создания заявки — 
чат помечается 🔵 
«заявка создана».

В карточке заявки — 
ссылка на чат Авито 
для быстрого перехода.

=== 6. АВТОМАТИЧЕСКИЕ УВЕДОМЛЕНИЯ ===

Когда приходит новое сообщение:
— Звук уведомления в CRM
— Счётчик непрочитанных 
  на иконке «💬 Сообщения» 
  в боковом меню
— Уведомление админу в Telegram:
  «Новое сообщение на Авито
  От: [имя клиента]
  Текст: [первые 50 символов]»

=== 7. СТАТИСТИКА АВИТО ===

Автоматически подтягивать 
статистику объявлений:

GET https://api.avito.ru/stats/v1/accounts/{user_id}/items
Headers:
Authorization: Bearer {access_token}

Сохранять по каждому объявлению:
— ID объявления
— Название
— Просмотры за день/неделю/месяц
— Контакты за день/неделю/месяц
— Стоимость контакта
— Статус (активно / неактивно)

Показывать в разделе 
«📊 Статистика Авито»:

Таблица объявлений:
Название | Просмотры | Контакты | 
Цена контакта | Статус

Цвет цены контакта:
🟢 до 150₽
🟡 150-300₽
🔴 больше 300₽

Обновлять статистику 
каждые 6 часов автоматически.

=== 8. БАЛАНС АВИТО ===

Подтягивать баланс автоматически:

GET https://api.avito.ru/core/v1/accounts/self/balance
Headers:
Authorization: Bearer {access_token}

Показывать в дашборде:
«💰 Баланс Авито: X₽»

Если баланс < 1 000₽:
— Показать красным
— Уведомление админу:
  «⚠️ Баланс Авито ниже 1 000₽»

Обновлять каждый час.

=== 9. ДОСТУПЫ ===

Экран «💬 Сообщения Авито» видят:
— Админ ✅
— Ассистент ✅

Экран «📊 Статистика Авито» видят:
— Админ ✅
— Ассистент ✅

Настройки Авито (токены, ключи):
— Только админ ✅
