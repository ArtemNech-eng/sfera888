## 1. Что мы строим

**Честные Мастера** — платформа для заказа ремонта и отделки в России. Два продукта:

1. **Маркетплейс** (`chestnye-mastera.ru`) — публичный SEO-сайт для клиентов. Кейсы мастеров, каталог, AI-дизайн, заявки.
2. **Платформа для мастеров** (`sfera-master.ru`) — CRM + PWA + лендинг регистрации. Мастера получают заявки, ведут сметы, работают через приложение.

---

## 2. Модель монетизации (для мастеров)

| Параметр | Значение |
|---|---|
| Подключение | **бесплатное** (0 ₽) |
| Стоимость заявки | **500 ₽** за каждую принятую заявку |
| Комиссия | **от 15%** с суммы заказа |
| Когда оплачивается | **по поступлению денег от клиента мастеру** (не по завершению объекта!) |
| Кто платит комиссию | мастер |
| Что получает клиент | бесплатный подбор мастера |

### Важные нюансы:
- Мастер **НЕ платит** ничего при подключении
- Мастер **НЕ платит** за заявку заранее — 500₽ + 15% списываются после того как клиент оплатил мастеру
- Если клиент отказался до оплаты — мастер ничего не платит
- Комиссия привязана к **поступлению денег**, а не к статусу "объект завершён"
- Один активный заказ в одни руки (для топов — до 2)
- Все сделки через приложение (смета, предоплата, закрытие)

## 4. Роли

| Роль | Где работает | Что делает |
|---|---|---|
| Клиент | chestnye-mastera.ru | Ищет мастера, смотрит кейсы, оставляет заявку |
| Мастер | sfera-master.ru/master-pwa | Получает заявки, выезжает на замер, делает смету, работает |
| Оператор | sfera-master.ru/crm | Распределяет заявки, контролирует качество, решает споры |
| Администратор | sfera-master.ru/crm | Полный контроль, настройки, финансы |

## 5. Процесс заказа (воронка)

```
Клиент оставляет заявку (маркетплейс / лендинг / Avito)
    ↓
Оператор в CRM видит лид (status: new)
    ↓
Оператор отправляет заявку в рассылку мастерам (send-to-buffer)
    ↓
Мастера в PWA видят заявку в ленте → откликаются
    ↓
Оператор назначает мастера (manual-assign / auto)
    ↓
Мастер выезжает на замер → считает смету в приложении
    ↓
Клиент вносит предоплату (через сервис)
    ↓
Мастер выполняет работу
    ↓
Клиент оплачивает остаток мастеру
    ↓
Мастер оплачивает комиссию (500₽ + 15%) — ПРИВЯЗАНО К ПОСТУПЛЕНИЮ ДЕНЕГ
    ↓
Мастер получает следующую заявку (конвейер)
```

## 8. Текущая модель мастера (для разработки)

Поля `masters` таблицы, актуальные для бизнес-логики:
- `status`: pending_contract → active → suspended
- `rating`: 0-5 (влияет на приоритет в рассылке)
- `totalOrders`, `acceptedOrders` — конверсия
- `consecutiveCancellations` — блокировка при 3+ отменах
- `maxActiveOrders`: 1 (default), 2 (для топов)
- `servicePrices[]` — прайс мастера (самооценка)
- `slug` — для публичного профиля на маркетплейсе (пока не используется повсюду)
