# Changelog: Исправление отображения имён мастеров

**Дата:** 2026-05-12  
**Проблема:** В CRM мастера отображались как "Мастер #37" вместо реальных имён

## Изменения в коде

### 1. API: Создание мастера (POST /api/masters)
**Файл:** `artifacts/api-server/src/routes/masters.ts` (строки 143-165)

**Добавлено:**
- ✅ Валидация: запрет имён вида "Мастер #123"
- ✅ Валидация: минимум 2 символа в имени
- ✅ Автоматический trim() при сохранении

```typescript
// Запретить автоматические имена вида "Мастер #123"
if (/^Мастер\s*#\d+$/i.test(alias.trim())) {
  return res.status(400).json({ error: "Укажите реальное имя мастера (не 'Мастер #ID')" });
}
```

## SQL скрипт для исправления существующих данных

**Файл:** `scripts/fix-master-names.sql`

Скрипт автоматически обновляет имена мастеров по приоритету:
1. Если есть телефон → "Мастер +7XXXXXXXXXX"
2. Если есть специализация → "Плиточник (Краснодар)"
3. Иначе → "Мастер 37 (Краснодар)"

## Что нужно сделать дальше

1. **Запустить SQL скрипт** для исправления существующих данных:
   ```bash
   psql -U your_user -d your_database -f scripts/fix-master-names.sql
   ```

2. **Вручную исправить имена** через CRM (если SQL скрипт дал временные имена)

3. **Перезапустить API сервер** для применения изменений в коде

## Технические детали

- Регулярное выражение для проверки: `/^Мастер\s*#\d+$/i`
- Минимальная длина имени: 2 символа
- Автоматический trim() убирает пробелы по краям
- Валидация работает на уровне API (не на уровне БД)
